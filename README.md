## 🌌 Overview
An interactive personal portfolio website blending the cinematic aesthetics of Marvel's **Doctor Strange & the Multiverse** with the software engineering, IoT telemetry, and conversational AI projects of **Binethma Jayawickrama** (Computer Science undergraduate at IIT Sri Lanka / University of Westminster).

---

## ✨ Key Features & Dimensions

### 1. Doctor Strange Sling-Ring Fiery Portal (`#portal-canvas`)
* Real-time HTML5 Canvas physics simulating tangential velocity spark ejection, flickering golden/amber/white embers, and radial light vortex.
* Interactive mouse attraction & clickable explosive dimension warp.

### 2. Interactive Moving Sorceress Avatar (`#mystic-companion`)
* Persistent bottom-right floating companion with reactive scroll-based commentary for each section.
* Clickable magic spell bursts casting confetti embers, audio effects, and cycling inspirational/witty quotes.
* Levitating meditation portrait card in the About section with aura glow and interactive whisper trigger.

### 3. Web Audio API Mystic Synthesizer (`src/audio.js`)
* Procedural sound effects with zero external audio assets:
  * Sling-Ring spark crackles
  * Dimensional portal resonant drone
  * Harmonic spell chimes
  * Time Stone reality rewind glissando
* Global audio toggle in the top HUD.

### 4. Time Stone Reality Warp
* Toggle button and interactive Eye of Agamotto rune dial shifting the entire universe into an emerald green time-warp aura.

### 5. Multiverse Dimensions (Projects Explorer)
1. **Adorix (Dimension AI-01)**: AI-Powered Conversational Sales Kiosk with face detection and low-latency speech synthesis.
2. **Smart Cattle Breeding & Heat Detection (Dimension IoT-02)**: Hardware & cloud telemetry with the proprietary non-invasive Smart Tail Pod sensor.
3. **ApexFled (Dimension COMM-03)**: High-performance digital e-commerce web platform.
4. **Vision Sync (Dimension CV-04)**: Contactless computer vision hand-gesture brightness controller.
5. **TeamFlow (Dimension OPS-05)**: Enterprise-grade collaborative sprint & Kanban orchestration workspace.
6. **WordSearch Quest (Dimension GAME-06)**: Algorithmic cross-platform mobile puzzle game built with Flutter & Dart.

### 6. The Sacred Timeline & Multiverse Chronicles
* Interactive temporal chronology tracking academic and project milestones from 2023 to present.
* In-depth engineering blog post-mortems for Adorix and the Smart Tail Pod.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build production bundle
npm run build
```
